# Windows 适配测试记录

日期：2026-10-26。基于提交 `6426203`，本地分支 `codex/windows-compatibility`。

## 测试环境

- Windows 11 专业版 x64，版本 10.0.26200。
- Node.js 24.19.0，npm 11.17.0；另用 Node.js 22.23.4 复测后端 25 项测试与构建产物冒烟测试，全部通过。
- Windows PowerShell 5.1；工作目录含中文 `琉璃`，隔离测试目录同时包含中文和空格。
- Electron 45.0.0，Playwright 1.64.1。

## 原项目结论

原桌面界面依赖 SwiftUI、AppKit、Darwin、macOS 截图和权限 API，Swift 包最低平台为 macOS 15；安装和打包脚本使用 Bash、make、codesign。它们不能直接生成 Windows 应用。Node 守护进程可复用，现已增加独立的 Electron Windows 桌面入口。

## 已复现并修复

1. SSE 客户端断开时监听了已结束的请求，模型仍继续生成。增加真实 HTTP 断开测试，改为监听响应关闭，并立即发送流响应头。
2. `~\` 家目录未展开；Windows 路径大小写不同会被错误判为越界。使用 Node 原生路径相对关系判断，补充盘符及反斜杠越界测试。
3. `.MD` 文档被忽略，CRLF front matter 进入检索摘要。统一扩展名判断并兼容 Windows 换行。
4. 原有端口冲突提示只给出 `lsof`。Windows 现在显示 PowerShell 查询命令，并提示更换端口。
5. 桌面启动场景没有 Windows 系统代理探测。增加限时、隐藏窗口的静态 HTTP(S) 系统代理读取，保留环境变量优先级与本地端口回退。
6. 新界面在模型切换尚未完成时可能发起下一任务。切换期间禁用提交，并在停止任务时等待后端取消。
7. 首次打包验证发现依赖精简规则误删 SDK 的 `clipboard-image.js`。改为只按原生依赖包名过滤其他平台文件，增加保留 SDK 模块与 Windows 二进制的回归测试。

## 当前功能范围

Windows 版已提供输入/划词翻译、直接框选截图翻译、截图 OCR、公式转 LaTeX 与本地排版预览、静默 OCR、解释/追问与本地 Wiki、模型/账号设置、历史、托盘和可调整的悬浮卡片。六组核心操作快捷键与 Mac 对齐，详见下方最新记录。Windows 使用 Acrylic 系统材质；macOS 使用 Liquid Glass / NSVisualEffectView。Mac 的系统权限页面、开机自启开关与跨应用阅读环境抓取尚未在 Windows 界面中对齐。Windows 10、ARM64 与多屏实机组合未在这台机器上验证。

## 2026-10-27：独立设置与悬浮卡片

Windows 界面改为两个独立原生窗口。启动展示设置窗口，分为通用、模型、账号、快捷键；Alt+A / Alt+D 和托盘入口仅唤起鼠标附近的无边框卡片。卡片无系统标题栏、跳过任务栏，支持拖动、Esc 收起、失焦收起、图钉固定，以及随结果内容调整高度。模型与账号配置不出现在卡片内。

通用设置保存默认目标语言、失焦收起选项和本地 Wiki 目录；快捷键支持录制、冲突检查、失败回滚与恢复默认。两个窗口通过受限 IPC 同步设置、模型和任务状态，卡片无权直接执行模型配置。关闭设置时清除未提交的密钥，取消进行中的登录。

桌面端到端测试覆盖：启动时卡片隐藏；两个窗口分离；设置语言立即同步；快捷键保存和注册；无标题栏及 DPI 容差；文本、追问、图片、模型切换、取消任务、测试登录/退出；失焦收起、置顶、Esc，以及退出清理后端。截图保存为 `dist/qa/floating-source.png` 和 `dist/qa/settings-source.png`；打包复测使用 `*-packaged.png`。

本机结果：桌面 4 项单元测试、源码端到端测试、新版 `.exe` 端到端复测全部通过。打包复测额外逐文件确认实际 `app.asar` 内的主进程、预加载和两个界面源码与当前工作区一致；并发保存通用设置不会相互覆盖。

通过 Windows 原生输入再次验证实际 Alt+A 唤起独立卡片、Esc 收起卡片；关闭和收起不影响设置窗口。2026-10-27 改版便携包另存为 `dist/Liuli-windows-x64-20261027.zip`，与前一版压缩包区分。

## 2026-10-27：直接划词与面板比例

Alt+D 在卡片激活前读取其他应用的选区。原生辅助程序优先使用 UI Automation TextPattern.GetSelection；不支持时等待快捷键松开，自动 Ctrl+C，并恢复之前的剪贴板内容。空选区不使用旧剪贴板，密码框拒绝读取，终端禁用 Ctrl+C 回退。辅助程序以隐藏进程运行，设有超时，随便携包分发；从源码运行、测试和打包时使用 Windows 自带的 .NET Framework 编译器构建，无需安装额外 SDK。

卡片保持约 480 逻辑像素宽；原文区域为 48–104 高，结果按内容增长，整窗上限约 640（DPI 会有少量取整差异），并受显示器工作区约束。长译文独立滚动，操作区和状态可见；用户向上阅读时不强制滚回末尾。修复了 Windows 下不可手动调整的窗口只增高、不缩小的问题，以及反复调整高度时宽度累积增长的问题。

自动测试增加另一窗口的真实文本选区 → 原生读取 → 卡片自动翻译，并强制测试模拟复制回退。核对原剪贴板纯文本、HTML 和 PNG 的 SHA-256 一致；验证空选区、密码框；测量短句高度、长原文/长译文、较小工作区下的滚动和底部可见性。界面截图为 `dist/qa/floating-short-source.png`、`floating-long-source.png`，打包测试使用对应的 `*-packaged.png`。

新增八个边缘/角落拖动区，保持卡片无系统边框。拖动后保存宽高，后续翻译不会覆盖手动尺寸；底部「自适应」、双击右下角或手柄上的 Home 恢复自动大小。方向键可微调尺寸，Shift+方向键每次调整 50。主进程负责屏幕边界、尺寸上下限和设置持久化，尺寸接口仅对卡片开放。尺寸计算测试覆盖负坐标显示器、最小尺寸、屏幕约束和拖动左/上边时保持对边位置；桌面单元测试现在共 6 项。完整链路另验证手动尺寸不被内容覆盖、文件保存、恢复自适应及设置窗口无权调整卡片。

## v0.2.2：手动主题与发布

通用设置新增「外观 → 主题」，提供跟随系统、浅色、深色。主进程统一设置 Electron nativeTheme.themeSource，并广播给设置窗口与隐藏卡片，使原生材质、标题栏和页面配色同步。选择持久化到 preferences.json；旧配置缺少主题字段时默认跟随系统，无效历史值安全回退。

端到端测试新增实际通过设置下拉框切换三个选项，核对 nativeTheme 与两个页面立即同步；拒绝无效主题；关闭并重新启动进程后确认浅色选择和两个页面状态保持。版本升级为 v0.2.2。发布工作流改为 Windows 和 macOS 产物均构建完成后再统一发布，避免出现只有部分附件的公开版本。

圆角虚影修复：显式关闭 DWM 自己的圆角与非客户区描边，使用随包分发的隐藏 WindowChrome.exe，以 Per-Monitor V2 DPI 感知获取窗口实际像素尺寸，通过 CreateRoundRectRgn / SetWindowRgn 统一裁切毛玻璃和内容。避免用逐逻辑像素矩形近似圆角时，在 150% 等缩放下留下阶梯状外沿。辅助进程只接受父 Electron 进程所属的 HWND，随应用退出，不读取其他窗口。

GitHub 托管 Windows runner 没有可用的前台 UI Automation 焦点。CI 现明确使用应用自己生成的选区文本和屏幕图像夹具，继续覆盖选区处理、框选交互、裁剪、模型请求、公式和主题；原生 UIA/复制回退及操作系统截图保留在本机交互桌面的完整检查中，输出中明确区分，不将夹具测试记作原生输入测试。


## 2026-10-27：v0.2.3 交互修订

本节覆盖前述冻结截图、Acrylic 材质及手动高度上限的旧行为。

托盘左键和右键均显示操作菜单，左键不会直接唤起卡片。截图覆盖层改为透明实时桌面，不创建屏幕图像；选区确认后将覆盖层置为全透明并忽略鼠标，再通过 Windows GDI BitBlt（包含 CAPTUREBLT）仅复制所选物理矩形，读取完成后销毁覆盖层。保留覆盖层激活状态直到取图结束，避免先销毁全屏窗口造成底层应用重排。原生辅助程序使用每屏 DPI 感知，选区通过 Electron dipToScreenRect 转为物理坐标，支持负坐标；不写截图临时文件。取消不会读取任何屏幕像素。

移除 Windows 系统 Acrylic 背景，使用卡片内半透明配色、CSS 抗锯齿圆角及物理窗口裁切，关闭原生非客户区边框与扩展框架。先前仅检查窗口区域不能证明实际桌面无阴影：本次用独立纯色背景实际读取合成桌面，在浅色/深色下分别检查 24,765 个卡片外围像素，与背景一致，0 个差异。图片为 dist/qa/corners-desktop-light.png 和 corners-desktop-dark.png。这项实测为本机 Windows 11、150% 缩放，不能代替未测试的 Windows/DPI 组合。

移除普通译文固定 260 像素高度限制，按内容增高至默认 640；用户拖动后的偏好高度允许增加最多 180，通常封顶 760，但尊重用户主动拖到更高的尺寸，且始终受屏幕工作区限制。长内容到达上限后独立滚动，短内容恢复紧凑，宽度保持。

13 项桌面单元测试通过。源码交互链路验证实际 Windows 选区抓图、本地 OCR、公式、静默精修、剪贴板竞争、取消及退出清理；CI 模式使用应用自有图像样本替代 OS 抓图，明确不计为本机原生取图验证。新增检查托盘左键打开菜单且卡片仍隐藏、取消无取图、无整屏缩略图调用、选择坐标为正确物理矩形、取图时覆盖层已全透明，以及手动高度的有限伸展。

远端检查发现任务完成响应可能先于流式 IPC 到达后台渲染进程，导致公式源码仍带 `$$`。任务加入本地请求标识，使用完成响应中的完整结果作为最终内容，忽略过期流事件。回归检查刻意扣留第一项任务的所有流事件，等待完成结果显示后再释放，验证结果不丢失或重复；后续公式、截图翻译和取消链路继续验证。


## 2026-10-27：v0.2.4 拖动与缩放

指针位置按 requestAnimationFrame 合并，上一条更新未结束时只保留最新位置，松手先提交最终位置再结束手势。缩放开始时一次启用原生 resize，过程中 setBounds 同时更新位置和尺寸，停止重复计算/提交原生圆角；结束时一次关闭 resize 并恢复裁切。移动后 100ms 再适配屏幕边界，布局消息和相同尺寸的圆角按值去重。

修正 340 的最低高度造成紧凑卡片一开始缩放就跳高的问题，最低高度与原窗口一致为 140。仅水平拖动保留原垂直容量。用户调高后本轮内容保留手动高度，后续编辑、输入、历史恢复或新翻译自动重新适配，不增加恢复按钮。

端到端测试用实际 Electron 窗口测得 40 次连续尺寸更新：setResizable 2 次、setShape 2 次、setBounds 40 次、原生 round 1 次、setPosition 0 次。另通过渲染器指针按下/40 次移动/松手，验证最终宽高对应 -50/-30 位移，松手不回弹，修改文字后解除手动高度。上述自动指针链路由 Playwright 对实际 Electron 窗口执行。续测另通过 Windows 原生鼠标实际拖动右下角，卡片由 420×246 变成 370×216 并保留高度。顶栏按帧指针拖动将原点由 (300,160) 移到 (360,200)，370×246 的尺寸不变；这也修复了圆角窗口的系统拖动命中不稳定。测试采用隔离配置和通用文字，没有修改用户账号或模型。


## 2026-10-27：v0.3.0 剪贴板历史

新增 Windows 原生 AddClipboardFormatListener 事件监听，不轮询剪贴板。文字、CF_HTML 富文本、PNG / Windows 位图经后台线程加密保存，默认保留 500 条，可设 100 / 500 / 1000 条并限制总容量为 128 MiB。索引和记录使用 AES-256-GCM，密钥由 Electron safeStorage / Windows 当前用户保护。搜索、加密与文件操作在 Node Worker 中执行，不占用翻译卡片的主进程手势路径。

Alt+V 唤起独立、无系统边框的搜索窗口，随内容数量自动收紧，最多显示有限高度并滚动。支持中文、多关键词、大小写兼容、图片缩略图、↑↓ / Enter / Alt+1–9、Ctrl+Delete 单条删除、暂停及通用设置。选中后只复制回剪贴板，由用户手动粘贴。遵循 ExcludeClipboardContentFromMonitorProcessing 与 CanIncludeInClipboardHistory 标记；不读取启动前或暂停期间的旧内容，划词翻译的内部复制过程暂停监听。

新增 4 项存储测试，覆盖格式保留、Unicode 查询、去重排序、并发保留上限、重启读取、密文无原文、错误密钥与篡改拒绝、清空及超限数据。桌面单元测试共 17 项。新增隔离配置的 Windows 原生事件端到端测试，实际写入系统剪贴板并验证文字、富文本、图片、排除标记、暂停/恢复、搜索、键盘复制、去重、删除、主题、自动高度、权限隔离、重启持久化和清空。源码完整翻译链路、打包版翻译与剪贴板链路均在本机运行；模型调用仍使用测试服务。

原生键盘自动化本轮无法激活测试窗口，因此未把实际物理 Alt+V 按键和跨应用焦点恢复计为通过；快捷键注册、菜单/设置入口、真实系统复制事件及 Electron 页面键盘操作已验证。明暗界面截图为 dist/qa/clipboard-light.png 和 clipboard-dark.png。

上一版 Release 的托管 Windows 打包后测试在退出阶段长时间挂起，已取消。测试清理新增有时限的正常退出，超过时限只终止本测试创建的进程树；正常退出检查仍要求不触发强制终止。Release 分离安装、检查、打包、打包验证和归档步骤，并设置 20 分钟上限，方便定位失败。v0.3.0 包含此前全部拖动/缩放优化。

## v0.4.0：模型直切与 Mac 剪贴板

Windows 卡片底部改为按服务商分组的原生模型下拉框。选择模型直接调用后端并保存，不显示设置窗口；切换期间禁用控件，过期的状态刷新不会覆盖新选择。账号登录等敏感接口继续只允许设置窗口调用。去掉常驻的更多、截图和重复追问按钮，保留与 Mac 对应的置顶、关闭、复制、重试与单个展开解释/追问入口；其余处理方式、图片和设置通过原生右键菜单或快捷键使用。

端到端测试检查卡片内切换文字/视觉模型、配置持久化、设置窗口仍隐藏、非视觉模型拒绝图片，以及右键菜单的图片、OCR 和设置入口。连续缩放测量前等待自动布局稳定；清空剪贴板后等待实际加密记录文件删除，避免把异步操作的中间状态当作失败。

Mac 此前只有翻译历史，本次新增独立的原生剪贴板面板，默认 ⌥V，选中后只复制，由用户自己粘贴。文字、HTML、RTF、PNG 使用 AES-256-GCM 加密，密钥保存在 Keychain；索引、去重、搜索和磁盘操作在独立 actor 中执行。默认保留 500 条，可选 100/500/1000 条并限制总容量；支持图片缩略图、暂停、清空和键盘选择。遵循 Concealed/Transient/AutoGenerated 标记与 macOS 剪贴板访问权限，跳过启动前、暂停期间和划词翻译内部的复制。

macOS CI 实际编译原生客户端，运行 5 项加密存储测试与 2 项命名剪贴板测试，覆盖真实 AppKit 文字/富文本/图片读写、隐私标记、暂停、立即搜索后回车、复制、重启读取、容量、错误密钥和篡改。7 项测试及 Release 编译通过；本机为 Windows，Mac 的实际全局快捷键、跨应用焦点和 Keychain 授权窗口尚未进行人工桌面测试。
